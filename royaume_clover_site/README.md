# Royaume de Clover - Site Black Clover RP

Site statique prêt à publier sur GitHub Pages.

## Installation GitHub Pages

1. Crée un dépôt GitHub, par exemple `royaume-clover`.
2. Ajoute les fichiers `index.html` et `style.css`.
3. Va dans **Settings > Pages**.
4. Dans **Build and deployment**, choisis :
   - Source : `Deploy from a branch`
   - Branch : `main`
   - Folder : `/root`
5. Clique sur Save.
6. Ton site sera disponible après quelques minutes.

## Modification

- Le texte principal est dans `index.html`.
- Les couleurs et le design sont dans `style.css`.
